Upload photos and videos of completed jobs here.

How to upload a file through GitHub (in your browser):
1. Open this folder (images) in your repository on github.com
2. Click "Add file" -> "Upload files"
3. Drag your photos/videos in from your computer
4. Scroll down and click "Commit changes"

Then in content.json (see the main README) reference the exact file name,
for example: images/job-1.jpg

Tips:
- Use simple file names with no spaces: job-1.jpg, before-after-2.mp4
- Compress photos before uploading so the site stays fast
- Keep videos short (10-30 sec) and in mp4 format
